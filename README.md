# مسار — منصة التتبع المدرسي

نسخة أولى محلية للمدارس الخاصة، كتجمع الحسابات والأقسام والدروس والتمارين المصححة أوتوماتيكياً والتقارير الأسبوعية والتواصل المرتبط بالتلميذ.

## المستويات

- Collège: 7ème (1AC)، 8ème (2AC)، 9ème (3AC).
- Lycée: Tronc Commun، 1BAC، 2BAC.

## التشغيل

ثبّت Node.js 24، ومن مجلد المشروع شغّل:

```powershell
npm install
npm run dev
```

في أول فتح، أنشئ حساب مدير المؤسسة. كلمات المرور خاصها تكون على الأقل 12 حرفاً. من بعد، المدير كينشئ حسابات الأساتذة والتلاميذ والوالدين، وكيضيف الأقسام ويربط الحسابات بها.

للتشغيل الإنتاجي داخل شبكة المدرسة:

```powershell
npm run build
npm run start -- -H 0.0.0.0
```

استعمل عنوان IP المحلي ديال السيرفر على أجهزة الشبكة. إعدادات Firewall خاصها تسمح بالاتصال من شبكة المدرسة فقط، وما تديرش port forwarding نحو الإنترنت. الوصول من خارج المدرسة خاصو VPN أو بوابة HTTPS آمنة.

## التخزين والبيانات

قاعدة البيانات فـ `data/school.sqlite`، ومرفقات PDF الخاصة بالدروس فـ `data/lesson-files/`. هاد الملفات مستثناة من Git. دير نسخ احتياطي منتظم لمجلد `data`، وخلي النسخ الاحتياطية مشفرة ومحدودة الوصول.

## الصلاحيات الحالية

- الإدارة: الأقسام والحسابات وربط التلاميذ وأولياء الأمور بالمدرسة.
- الأستاذ: نشر درس نصي أو PDF، إنشاء تمارين QCM، رؤية نتائج وتقارير تلاميذ أقسامه، والتواصل مع الأسرة.
- التلميذ: رؤية دروسه، حل التمارين، ورؤية نتيجته بعد التسليم.
- ولي الأمر: رؤية تقرير الابن وتمارينه ورسائله المدرسية فقط.

التصحيح الحالي أوتوماتيكي لأسئلة الاختيار من متعدد. لا يوجد chatbot أو تصحيح للكتابة الحرة في هذه النسخة.
